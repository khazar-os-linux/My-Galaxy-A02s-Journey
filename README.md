**STATUS**: Yes (Unofficial)
- Unofficial [TWRP](https://github.com/khazar-os-linux/My-Galaxy-A02s-Journey/raw/refs/heads/main/resources/twrp-3.7.1-a02q-unofficial.img.tar)

## Custom Kernel Availibilty
**STATUS:** Yes (but only for arm64 vendor)
> Avialable but only for [arm64 vendor](https://github.com/ifoodplayer/android_kernel_samsung_sdm450/releases).
> 
> If you found one, please open up a PR or report it here as an issue.

## Custom ROM Availibility - For Those Who Hates Sticking To Stock OS Like Me
**STATUS**: GSI Compatible, no Custom ROM available.

> [!IMPORTANT]
> If you didn't flashed an arm64 vendor, **INSTALL ONLY a64 or arm32_binder64 GSI's**.
> If you flashed TWRP which I gave, **DO NOT WIPE THE sdcard PARTITION** if you don't want to enter the QDL mode.
> If you managed to flash the arm64 vendor, please create an issue about it, I will pin it here
